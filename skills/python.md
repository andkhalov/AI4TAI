# Python — правила написания и проверки

## Цикл выполнения

1. Понять требования; неясное уточнить одной фразой.
2. Написать минимальный вариант в файл.
3. Запустить: `python file.py` или `python -m pytest file.py`.
   В репозитории AI4TAI — `.venv\Scripts\python.exe` (Windows) или
   `.venv/bin/python`.
4. Прочитать вывод. Ошибка — исправить в том же файле, запустить снова.
5. Максимум 5 итераций. После пятой — остановиться, описать гипотезу о
   причине, спросить пользователя.

Код, который не запускался в этой сессии, пользователю не отдаётся.

## Окружение

- Проверить наличие `.venv/`. Есть — использовать его интерпретатор.
  Нет и нужны сторонние пакеты — создать: `python -m venv .venv`.
- Зависимости — в `requirements.txt`; установка `pip install -r`.
- Стандартная библиотека предпочтительнее стороннего пакета, если
  задача решается за 20 строк.

## Стиль

- Функции короткие, с типами аргументов и docstring в одну строку.
- Пути — `pathlib.Path`. Кодировка файлов — `encoding="utf-8"` явно.
- Секреты — из переменных окружения или `.env`, не в коде.
- Вывод для человека — `print`; вывод для машины — JSON.

## MCP-инструмент

```python
from mcp.server.fastmcp import FastMCP
mcp = FastMCP("my-tools")

@mcp.tool()
def check_url(url: str) -> str:
    """Вернуть HTTP-статус страницы. Только чтение."""
    import requests
    try:
        r = requests.head(url, timeout=10, allow_redirects=True)
        return f"{url}: HTTP {r.status_code}"
    except Exception as e:
        return f"ERROR: {type(e).__name__}: {e}"

if __name__ == "__main__":
    mcp.run()
```

- Возвращать строку. Ошибки — строкой `ERROR: ...`.
- Docstring — для модели: что делает, что возвращает, побочные эффекты.
- Проверка: запустить файл (ждёт stdin — это нормально), затем
  подключить в recipe и вызвать через агента.

## Проверка

- Тест `pytest` для функций с логикой.
- Прогон на реальном примере входных данных.
- В отчёте пользователю — команда запуска и фактический вывод.
