# Markdown — документы проекта

## Файлы памяти проекта

| Файл | Правило |
|---|---|
| `AGENT.md` | Правила для агента. Разделы: роль, язык, что можно, что нельзя, отчёт, память, соглашения. Менять по просьбе пользователя. |
| `DIARY.md` | Append-only. Запись: дата, запрос, результат, проверка, замечания. Старые записи не редактировать. |
| `CONTEXT.md` | Текущее состояние: в работе, сломано, дальше, ключевые файлы. Перезаписывать при изменении состояния. |
| `docs/*.md` | Документация. Ссылки между файлами: `[[имя-файла]]` или относительный путь. |
| `README.md` | Как запустить. Только по просьбе пользователя. |

## Структура документа

- Один заголовок `#` на файл, дальше `##` и `###`.
- Короткие абзацы. Списки для перечислений, таблицы для сравнений.
- Команды и пути — в обратных кавычках; блоки команд — с указанием
  языка (```powershell, ```sql, ```python).
- Первая строка после заголовка — назначение документа в одном
  предложении.

## Запись в DIARY.md

```
## 2026-09-15 — Оптимизация запроса остатков
Запрос: переработать запрос из tasks/day1/slow_query_1c.txt.
Результат: docs/query_v2.txt — временная таблица + левые соединения.
Проверка: сравнение выборки на тестовой базе, 1 240 строк, суммы совпали.
Замечания: агент предложил ВНУТРЕННЕЕ соединение, заменено на ЛЕВОЕ.
```

## Стиль

- Утверждения и описания. Без противопоставлений «не X, а Y», без
  оценок, без обращений к читателю.
- Термины — как в проекте. Английские имена команд и файлов без перевода.
- Кодировка UTF-8, перевод строки LF.
