# Язык запросов 1С — чтение и оптимизация

## Контекст

Запросы 1С выполняются поверх СУБД (MS SQL Server, PostgreSQL) после
трансляции платформой. Виртуальные таблицы (`Остатки`, `Обороты`,
`СрезПоследних`) разворачиваются в подзапросы с группировкой. Ошибки
производительности возникают в местах, где платформа не может
передать отбор внутрь виртуальной таблицы или где запрос выполняется
многократно.

## Порядок разбора запроса

1. Найти источники: `ИЗ`, соединения, виртуальные таблицы и их параметры.
2. Найти подзапросы в списке выборки и в условиях `ГДЕ`, `В (...)`.
3. Найти соединения без условия (запятая между таблицами) и условия
   соединения по неиндексированным полям.
4. Найти отборы, применённые после соединения, вместо параметров
   виртуальной таблицы.
5. Найти функции над полями в условиях (`ПОДСТРОКА`, `ВЫРАЗИТЬ`,
   `ПОДОБНО "%..."`), мешающие использовать индекс.
6. Найти `В ИЕРАРХИИ`, `РАЗЛИЧНЫЕ`, `УПОРЯДОЧИТЬ` по вычисляемым полям.

## Типовые проблемы и замена

| Проблема | Замена |
|---|---|
| Коррелированный подзапрос в списке выборки | Левое соединение с виртуальной таблицей, отбор в параметрах |
| Отбор по номенклатуре в `ГДЕ` после `Остатки(...)` | Отбор в параметрах: `Остатки(&Дата, Номенклатура В (&Список))` |
| Соединение через запятую | `ВНУТРЕННЕЕ` / `ЛЕВОЕ СОЕДИНЕНИЕ ... ПО` |
| `В (ВЫБРАТЬ ...)` с большим подзапросом | Временная таблица, затем соединение |
| Соединение с подзапросом | Временная таблица с индексом (`ИНДЕКСИРОВАТЬ ПО`) |
| `ПОДОБНО "%текст%"` по большому справочнику | Отбор по реквизиту с индексом или полнотекстовый поиск |
| Запрос в цикле | Один запрос со списком параметров |
| Получение реквизитов через точку в цикле | Запрос с нужными полями |

## Шаблон переработки

```
ВЫБРАТЬ Ссылка ПОМЕСТИТЬ ВТ_Номенклатура
ИЗ Справочник.Номенклатура
ГДЕ Ссылка В ИЕРАРХИИ(&Группа) И НЕ ПометкаУдаления
ИНДЕКСИРОВАТЬ ПО Ссылка;

ВЫБРАТЬ
    ВТ.Ссылка КАК Номенклатура,
    Ост.Склад,
    ЕСТЬNULL(Ост.ВНаличииОстаток, 0) КАК ВНаличии
ИЗ ВТ_Номенклатура КАК ВТ
ЛЕВОЕ СОЕДИНЕНИЕ РегистрНакопления.ТоварыНаСкладах.Остатки(
        &Дата, Номенклатура В (ВЫБРАТЬ Ссылка ИЗ ВТ_Номенклатура)
               И Склад В (&Склады)) КАК Ост
    ПО Ост.Номенклатура = ВТ.Ссылка
```

## Проверка без доступа к базе

- Прочитать запрос по шагам выше и назвать конкретные конструкции.
- Оценить порядок числа обращений: строки × подзапросы.
- Предложить переработанный запрос с тем же набором полей.
- Указать, что нужно проверить в базе: консоль запросов, замер
  производительности, план запроса в СУБД.
- Изменение результата запроса недопустимо; при сомнении — сказать,
  чем результат может отличаться (например, `ЛЕВОЕ` vs `ВНУТРЕННЕЕ`).

## Ограничения

- Модель не знает состав конкретной конфигурации. Имена регистров и
  реквизитов брать из текста запроса и из документации проекта, не
  выдумывать.
- Доступ к продуктивной базе для проверки не запрашивать; работа
  ведётся на тестовой копии.
