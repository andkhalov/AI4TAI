# Регламент выдачи средств индивидуальной защиты (СИЗ)

Документ учебный. Составлен для практики по RAG в интенсиве AI4TAI.
Номер: РГ-СИЗ-03. Версия 2.1 от 15.03.2026.

## 1. Область применения

Регламент определяет порядок выдачи, замены, учёта и списания СИЗ
работникам склада, производства и выездных бригад.

## 2. Основания выдачи

2.1. СИЗ выдаются по нормам, утверждённым приказом о типовых нормах
для должности, и по результатам специальной оценки условий труда.

2.2. Работнику, принятому на работу, СИЗ выдаются в первый рабочий
день до допуска к работе. Основание — заявка руководителя подразделения
в системе 1С:ЗУП, статус «Согласована».

2.3. Замена СИЗ до истечения срока носки производится при:
- утрате защитных свойств (разрыв, износ подошвы, повреждение каски);
- изменении размера работника;
- переводе на другую должность с иными нормами.

## 4. Порядок выдачи со склада

4.1. Кладовщик выдаёт СИЗ по расходной накладной из 1С. Накладная
формируется автоматически из согласованной заявки.

4.2. Работник расписывается в личной карточке учёта выдачи СИЗ.
Карточка ведётся в электронном виде в 1С:ЗУП; бумажная копия
распечатывается один раз в год.

4.3. При выдаче каски кладовщик проверяет дату выпуска. Каски старше
3 лет к выдаче не допускаются и списываются.

4.4. Респираторы FFP2 и FFP3 выдаются упаковками по 10 штук на
подразделение, учёт ведётся по подразделению, а не по работнику.

## 5. Дежурные СИЗ

5.1. Дежурные СИЗ (щитки лицевые, наушники на каску, диэлектрические
перчатки) закреплены за рабочим местом и хранятся у мастера участка.

5.2. Диэлектрические перчатки испытываются один раз в 6 месяцев.
Штамп испытания ставится на манжете. Перчатки без штампа или с
истёкшим сроком использовать запрещено.

## 6. Списание

6.1. СИЗ списываются актом комиссии при истечении срока носки или
утрате защитных свойств. Акт оформляется в 1С документом
«Списание материалов» с видом операции «Списание СИЗ».

6.2. Утраченные по вине работника СИЗ заменяются по докладной
записке руководителя; стоимость может быть удержана в порядке,
установленном трудовым законодательством.

## 7. Ответственные

- Руководитель подразделения — заявка, контроль применения СИЗ.
- Кладовщик — выдача, учёт, контроль сроков.
- Специалист по охране труда — нормы, проверка карточек раз в квартал.
- ИТ-департамент — работоспособность обработки «Карточка СИЗ» в 1С:ЗУП
  и обмена с сайтом по номенклатуре.
