# Политика паролей и доступа

Документ учебный. ИТ-департамент, ПЛ-ИБ-01, версия 2.0 от 01.02.2026.

## 1. Пароли учётных записей домена

- Минимальная длина 12 символов.
- Смена не реже одного раза в 180 дней; для администраторов — 90 дней.
- Запрещено использовать пароль, совпадающий с любым из 10 предыдущих.
- Блокировка учётной записи после 7 неверных попыток на 30 минут.

## 2. Служебные учётные записи

- Служебные учётные записи (обмен с сайтом, резервное копирование,
  мониторинг) не используются для интерактивного входа.
- Пароли служебных учётных записей хранятся только в менеджере паролей
  ИТ-департамента. Хранение в файлах конфигурации в открытом виде
  запрещено; допускается хранение в переменных окружения сервера и в
  файле `.env`, исключённом из системы контроля версий.

## 3. Доступ к 1С

- Доступ к продуктивным базам выдаётся по заявке руководителя.
- Роль «Полные права» — только у администраторов 1С, не более трёх
  человек.
- Разработка ведётся в тестовой копии базы; перенос изменений в
  продуктивную базу — через хранилище конфигурации.

## 4. Удалённый доступ

- RDP к серверам разрешён только через RDP-шлюз и только из VPN.
- Прямое открытие порта 3389 в интернет запрещено.
- Сессии RDP завершаются автоматически после 8 часов бездействия.

## 5. Работа с ИИ-сервисами

- В облачные ИИ-сервисы запрещено передавать: персональные данные
  работников и клиентов, данные из продуктивных баз 1С, пароли, ключи,
  файлы конфигурации VPN, коммерческие условия договоров.
- Разрешено передавать: обезличенные фрагменты кода и запросов,
  тексты ошибок без идентификаторов, публичную документацию.
- Для задач с конфиденциальными данными используется локальная модель
  на сервере ИТ-департамента.
- Результат работы ИИ-инструмента проверяется сотрудником до
  применения в продуктивной среде.

## 6. Нарушения

О компрометации пароля или ключа сотрудник сообщает в службу
поддержки немедленно. Ключ или пароль заменяется в день обращения.
