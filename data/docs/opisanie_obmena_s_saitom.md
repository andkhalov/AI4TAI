# Описание обмена 1С:УТ с сайтом technoavia.ru

Документ учебный. Версия 1.2 от 11.08.2026. Автор: ИТ-департамент.

## 1. Назначение

Обмен передаёт из 1С:УТ на сайт номенклатуру, цены и остатки, а с
сайта в 1С — заказы покупателей. Обмен работает по HTTP-сервису 1С
(OData и собственный REST) и по API сайта.

## 2. Направления

| Направление | Данные | Периодичность | Механизм |
|---|---|---|---|
| 1С → сайт | Номенклатура: артикул, наименование, категория, свойства | каждые 6 часов и по кнопке | регламентное задание `ОбменССайтом_Номенклатура` |
| 1С → сайт | Цены и остатки по складам | каждые 15 минут | регламентное задание `ОбменССайтом_Остатки` |
| сайт → 1С | Заказы покупателей | по вебхуку сайта, повтор каждые 10 минут | HTTP-сервис `orders/incoming` |

## 3. Идентификация

Ключ сопоставления — артикул (поле `clear_sku` на сайте, реквизит
`Артикул` справочника Номенклатура в 1С). Артикул уникален в пределах
справочника. Позиции без артикула на сайт не передаются и попадают в
отчёт «Ошибки обмена».

## 4. Остатки

На сайт передаётся доступный остаток: `ВНаличии − ВРезерве` по складам
с признаком «Публиковать на сайте». Склады: MSK-01, SPB-01, EKB-01,
NSK-01. Отрицательный доступный остаток передаётся как 0.

Источник истины по остаткам и ценам — 1С. Данные на сайте могут
отставать до 15 минут.

## 5. Заказы

Заказ с сайта создаёт документ «Заказ клиента» со статусом «Новый».
Обязательные поля: номер заказа сайта, контрагент (по ИНН или e-mail),
строки с артикулом, количеством и ценой на момент заказа.

Если артикул из заказа не найден в 1С, заказ создаётся, строка
помечается комментарием «Артикул не найден», задача уходит менеджеру.

## 6. Ошибки и диагностика

Журнал обмена: регистр сведений `ЖурналОбменаССайтом`. Уровни: Ошибка,
Предупреждение, Информация. Хранение 90 дней.

Типовые ошибки:
- `HTTP 401` от API сайта — истёк токен, обновить в константе
  `ТокенAPIСайта`.
- `HTTP 302` с HTML в теле — запрос перехвачен защитой от ботов,
  проверить адрес API и заголовок User-Agent.
- «Не найден склад» — склад без признака «Публиковать на сайте»
  используется в остатках.
- Регламентное задание не запускается — проверить, что на кластере
  разрешён запуск регламентных заданий и задание не заблокировано
  другим сеансом.

## 7. Планы

- Перевод обмена остатками на вебхуки при изменении (сейчас опрос).
- Передача документов сертификации по позициям (файлы `/products/{id}/files`).
