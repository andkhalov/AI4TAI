# Задачи дня 1 — «найди ошибку»

Три файла, в каждом одна ошибка. Выбирается один по профилю.
Запуск агента из этой папки:

```powershell
cd tasks\day1
..\..\bin\ai4tai.bat
```

Запрос агенту: «В этой папке лежит файл `<имя>`. Найди причину ошибки,
объясни её и предложи исправление. Ничего не удаляй.»

| Файл | Профиль | Что внутри |
|---|---|---|
| `wireguard.log` | администраторы | журнал клиента WireGuard, туннель не поднимается |
| `report_disks.ps1` | администраторы, программисты | скрипт отчёта по дискам, падает на одном из серверов |
| `slow_query_1c.txt` | 1С-разработчики | запрос отчёта по остаткам, выполняется несколько минут |

Проверка результата: агент называет конкретную строку или конструкцию
и объясняет, почему она ведёт к ошибке. Ответ сверяется с
`EXPECTED.md`.
