# Шпаргалка: команды и режимы AI4TAI

Одна страница. Печатается или лежит открытой во время практики.

## Запуск

| Команда | Что делает |
|---|---|
| `bin\ai4tai.bat` | интерактивная сессия в текущей папке |
| `bin\ai4tai.bat run "<задача>"` | одна задача и выход |
| `bin\ai4tai.bat doctor` | проверка: ключ, Goose, база, MCP, бюджет |
| `bin\ai4tai.bat -m junior` | экономичная модель (домашний режим) |
| `bin\ai4tai.bat --mode approve` | подтверждение каждого действия |
| `bin\ai4tai.bat --site mock` | сайт только из локальной копии каталога |

macOS и Linux: `./setup.sh` при установке, дальше `ai4tai` вместо
`bin\ai4tai.bat`.

## В сессии

| Команда | Что делает |
|---|---|
| `/mode approve` | переключить режим подтверждений на лету |
| `/mode smart_approve` | чтение без вопросов, запись и команды с подтверждением |
| `/plan <задача>` | сначала план, потом выполнение |
| `/summary` | сжать историю диалога вручную |
| `/exit` | выйти |
| `Ctrl-C` | прервать текущее действие |

## Инструменты агента

| Инструмент | Для чего |
|---|---|
| `sqlite_schema`, `sqlite_query` | учебная база: номенклатура, склады, остатки, заказы |
| `site_search`, `site_product`, `site_categories` | каталог technoavia.ru |
| `rag_search`, `rag_status` | поиск по проиндексированным документам (день 2) |
| `web_search`, `web_fetch` | интернет |
| `pdf_info`, `pdf_read`, `pdf_search` | локальные PDF |
| `list_skills`, `load_skill` | инструкции по областям |
| `token_budget` | расход токенов за сутки |

Файлы и команды агент выполняет встроенными инструментами: `shell`,
`write`, `edit`, `tree`.

## Как формулировать задачу

1. Что сделать и с каким файлом или источником.
2. Куда положить результат: имя файла и «в текущей папке».
3. В каком виде: таблица, список, короткий разбор.
4. Что проверить: «сверь одну цифру отдельным запросом», «покажи
   строки, на которых основан вывод».

Пример:

```
Разбери eventlog_system.csv: найди ошибки резервного копирования, объясни причину и подтверди её данными из disks.csv. Сохрани разбор в backup_incident.md в текущей папке, укажи строки файлов, на которых основан вывод.
```

## Правила работы

1. Контекст — в `AGENT.md`, а не в переписке.
2. Каждый результат проверяется: запуск, тест, сверка с источником.
3. Три неудачные попытки — дальше разбираемся сами.
4. Режим подтверждения выбирается по рискованности задачи.
5. В папке агента нет рабочих учётных записей и паролей.
6. В `DIARY.md` — запрос, результат, способ проверки.

## Если что-то не работает

| Симптом | Действие |
|---|---|
| `python` не найден | переустановить Python с галочкой PATH, новое окно PowerShell |
| `doctor`: `MCP ai4tai: FAIL` | удалить `.venv`, запустить `setup.bat` снова |
| ошибка 401 от провайдера | `del .env`, `setup.bat`, ввести ключ заново |
| кириллица в консоли ломается | `chcp 65001` или Windows Terminal |
| файл создан не в той папке | работать в `C:\ai4tai-work`, писать «в текущей папке» |
