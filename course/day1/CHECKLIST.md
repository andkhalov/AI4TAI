# Чек-лист подготовки к занятию

Рассылается слушателям за день до первой встречи. Занимает 15–20 минут.

## 1. Ноутбук

- [ ] Windows 10 или 11, права на установку программ.
- [ ] Свободно не менее 2 ГБ на диске.
- [ ] Доступ в интернет (Wi-Fi аудитории или свой).

## 2. Python 3.10 или новее

Проверка в PowerShell:

```powershell
python --version
```

Если команда не найдена: установить с python.org, при установке
отметить «Add python.exe to PATH», затем открыть новое окно PowerShell
и проверить снова.

## 3. Git

```powershell
git --version
```

Если не найден: установить с git-scm.com, параметры по умолчанию.

## 4. Редактор

Любой: VS Code, Notepad++, встроенный «Блокнот» тоже подойдёт для
правки `AGENT.md`.

## 5. Рабочая папка

```powershell
mkdir C:\ai4tai-work
```

Короткий путь без пробелов и кириллицы. Всё, что делаем на курсе,
живёт здесь.

## 6. Проверка сети

```powershell
Test-NetConnection github.com -Port 443
Test-NetConnection llm.api.cloud.yandex.net -Port 443
```

Обе строки должны показать `TcpTestSucceeded : True`. Если нет —
сообщить в чат курса до занятия.

## 7. Что приносить с собой

- Ноутбук и зарядное устройство.
- Одну свою рабочую задачу, на которой хочется попробовать агента.
  Данные брать обезличенные или учебные.

## Чего делать не нужно

- Устанавливать агент заранее — ставим вместе на занятии.
- Заводить ключи Yandex AI Studio — выдаются на первой встрече.
