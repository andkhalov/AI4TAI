# Раздаточные материалы дня 1

Папка выдаётся слушателям в начале занятия (файлом или ссылкой) и
остаётся у них после курса.

| Файл или папка | Назначение |
|---|---|
| `CHECKLIST.md` | подготовка ноутбука до занятия |
| `SHPARGALKA.md` | команды, режимы, инструменты, правила, типовые ошибки |
| `DIARY_template.md` | шаблон журнала работы с агентом |
| `agent_examples/AGENT_admin.md` | готовый `AGENT.md` для системного администрирования |
| `agent_examples/AGENT_1c.md` | готовый `AGENT.md` для 1С-разработки |
| `agent_examples/AGENT_analytics.md` | готовый `AGENT.md` для аналитики |
| `demo_admin/` | выгрузки с условных серверов для практики без доступа к рабочим системам |

## Порядок использования на занятии

1. Установка агента по `CHECKLIST.md` и `practice.md`.
2. Практика на своей машине: паспорт системы, отчёт из учебной базы.
3. Практика по профилю: сценарий из `practice.md` или задача на данных
   `demo_admin/`.
4. Копирование подходящего примера из `agent_examples/` в рабочую
   папку под именем `AGENT.md`, правка под себя.
5. Записи в `DIARY.md` по шаблону.
