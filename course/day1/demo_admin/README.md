# Данные для практики по администрированию

Учебные выгрузки, снятые с условных серверов департамента. Ключи и
пароли заменены заглушками, адреса вымышленные. Файлы нужны, чтобы
разобрать реальные задачи администрирования без доступа к рабочим
серверам: агент работает с этими файлами, а не с продуктивной средой.

| Файл | Что внутри | Задача, которую на нём ставят |
|---|---|---|
| `services_msk-app20.txt` | вывод `Get-Service` по службам 1С, SQL, IIS | найти остановленные службы, которые должны работать |
| `netstat_listen.txt` | открытые TCP-порты с процессами | определить, какие порты нужны для 1С и SQL, какие лишние |
| `disks.csv` | диски шести серверов, объём и свободное место | найти серверы у порога, оценить риск для резервных копий |
| `eventlog_system.csv` | ошибки журнала System за сутки | связать события в одну причинно-следственную цепочку |
| `rdp_gateway.log` | журнал RDP-шлюза | объяснить отказы двух пользователей: разные причины |
| `servers.csv` | реестр серверов: роль, адрес, площадка, режим копий | сверить реестр с фактическими данными из других файлов |
| `wireguard_client.conf` | конфигурация клиента VPN (с заглушками) | найти причину недоступности серверного сегмента |

## Как использовать на занятии

Скопировать папку в рабочую папку и запустить агента из неё:

```powershell
Copy-Item -Recurse <путь>\handout\demo_admin C:\ai4tai-work\demo_admin
cd C:\ai4tai-work\demo_admin
C:\ai4tai-work\AI4TAI\bin\ai4tai.bat
```

Примеры задач:

```
В этой папке лежат выгрузки с серверов. Найди в eventlog_system.csv ошибки резервного копирования, объясни их причину и подтверди её данными из disks.csv. Ответ — короткий разбор с указанием файлов и строк.
```

```
Составь по servers.csv и disks.csv таблицу: сервер, роль, минимальный процент свободного места, режим резервного копирования, риск. Отсортируй по риску. Сохрани в disk_risk.md.
```

```
По netstat_listen.txt и services_msk-app20.txt объясни, какие порты открыты службами 1С и SQL, а какие относятся к службам Windows. Отдельно отметь порты, которые не должны быть доступны из офисной сети.
```

```
Разбери rdp_gateway.log: почему у одного пользователя отказ, а у другого разрыв. Это две разные причины — назови обе и предложи, что проверить.
```

## Что проверять после ответа агента

- Названы конкретные строки или записи из файлов, а не общие
  рассуждения.
- Числа в ответе совпадают с числами в файлах.
- Различены две причины в `rdp_gateway.log`: отказ по политике
  (`RAP_no_match`) и недоступность целевого сервера
  (`target_unreachable`, совпадает по времени с ошибками SQL).
- Связь между `eventlog_system.csv` (ошибка 3201, нехватка места) и
  `disks.csv` (диск `E:` на msk-app20, 4,8 % свободно) установлена.
